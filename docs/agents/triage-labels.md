# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting on the reporter for information |
| ready-for-agent | ready-for-agent | Fully specified; ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use this mapping whenever an engineering skill names a triage role.
Create missing labels and preserve existing labels and their metadata.
